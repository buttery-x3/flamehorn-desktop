# Flamehorn Desktop

A local desktop for exploring conversational material, controlling context and composing model interactions.

**Current state: design/documentation only. No application has been implemented.**

Start at [docs/agent-brief-mvp.md](docs/agent-brief-mvp.md) for the approved scope and candidate implementation prompt, or [docs/README.md](docs/README.md) for the six specifications.

[Open the visual reference pack](docs/design/mockups/index.html) — 19 full-size panels in Charcoal and Light, with current-rule qualifications.

The user accepted the design recommendations on 13 October 2026. Final handoff review is [FLAME-145](https://linear.app/flamehorn-games/document/mvp-implementation-brief-and-handoff-a5ec8958adc5); a later explicit instruction is required to begin the MVP build.

The local checkout is `D:\dev\flamehorn-desktop`; the remote is [buttery-x3/flamehorn-desktop](https://github.com/buttery-x3/flamehorn-desktop). The source aims to become open source; a product licence has not yet been selected.

## Development and user testing

Follow the [repository development contract](docs/repo-development-contract.md): features enter development through reviewed PRs, usable model-approved milestones move to testing, and main receives implementation only after the user tests and explicitly approves the exact candidate. The first main implementation must be the complete MVP.

[Testing updates](docs/testing/README.md) records what is included and what to test in each future testing push. No application candidate exists yet. Main retains the original documentation baseline; current working instructions live on development.
