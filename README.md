# Flamehorn Desktop

A local desktop for exploring conversational material, controlling context and composing model interactions.

**Current state: design/documentation only. No application has been implemented.**

Start at [docs/agent-brief-mvp.md](docs/agent-brief-mvp.md) for the approved scope and candidate implementation prompt, or [docs/README.md](docs/README.md) for the six specifications.

[Open the visual reference pack](docs/design/mockups/index.html) — 19 full-size panels in Charcoal and Light, with current-rule qualifications.

The user accepted the design recommendations on 13 October 2026. Final handoff review is [FLAME-145](https://linear.app/flamehorn-games/document/mvp-implementation-brief-and-handoff-a5ec8958adc5); a later explicit instruction is required to begin the MVP build.

This is the local Git repository at `D:\dev\flamehorn-desktop`. A remote repository has not been created or configured. The source aims to become open source; a product licence has not yet been selected.
